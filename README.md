# 🤖 DocuChat AI

An intelligent PDF Question Answering system built with Streamlit, LangChain, ChromaDB, and HuggingFace Embeddings.

Upload PDF documents, store their embeddings in a vector database, and instantly ask questions about the content using Retrieval-Augmented Generation (RAG) techniques.

---

## 🚀 Features

- 📄 Upload PDF documents
- ✂️ Automatic text chunking
- 🧠 Semantic search using embeddings
- 🗂 Vector storage with ChromaDB
- 💬 Interactive chat interface
- ⚡ Fast document retrieval
- 🎯 Context-aware answers from uploaded PDFs

---

## 🛠 Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace Embeddings
- PyPDFLoader
